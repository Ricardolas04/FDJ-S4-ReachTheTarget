# Reach the Target
## Engine
Godot 4 .NET / Unity
Ferramentas de Desenvolvimento de Jogos | Semana 4
Tutorial prático - Reach the Target | Godot 4 .NET e Unity | Página 12
## Objetivo
Controlar o jogador e alcançar todos os objetivos.
## Controlos
WASD ou setas.
## Funcionalidades
- Movimento do jogador em 2D.
- Deteção de colisões.
- Interação com Targets.
- Feedback visual ao atingir os objetivos.

## Melhorias implementadas
- Implementação de um sistema de pontuação no Unity.
- Reposicionamento aleatório do Target após cada colisão.
- Atualização do contador de pontos em tempo real.
- Condição de vitória ao atingir 5 pontos.
- Apresentação da mensagem "GANHASTE!" no final do jogo.
